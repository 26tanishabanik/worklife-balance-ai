# worklife-balance-ai

## Description:

🚀 WorkLife Balance AI is a Retrieval-Augmented Generation (RAG) powered system that analyzes discussions on work-life balance, extracts key insights, and quantifies opinions using LLMs (Amazon Bedrock). It features guardrail-based filtering, vector search, and Datapane-based monitoring for performance tracking. This AI pipeline fetches relevant discussions from Reddit, filters unsafe content using AWS Guardrails, embeds text into a ChromaDB vector store, and quantifies sentiment across multiple dimensions (support, balance, stress, and family time emphasis). Datapane-based reports provide real-time insights, making it a robust monitoring tool for workplace discussions.

## Key Features:
✅ Reddit-powered insights – Fetches and analyzes relevant discussions.

✅ AWS Guardrails – Ensures content safety before processing.

✅ Amazon Bedrock LLMs – Advanced AI-based opinion quantification.

✅ ChromaDB Vector Store – Enables efficient document retrieval.

✅ Datapane Monitoring – Real-time reports for tracking key metrics.

✅ Production-Ready – Modular, scalable, and well-structured for deployment.

## Use Cases:
🔹 AI-driven work-life balance sentiment tracking.

🔹 Content safety enforcement – Guardrails prevent unsafe queries.

🔹 AI-powered work life balance research – Automated opinion extraction.
